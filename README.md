# Crumb

you're just a little guy. a tiny ant crosses a giant house (kitchen, living room, backyard), grabbing crumbs for more time while giant feet stomp down.

Play it: [[your itch.io link]](https://mytra.itch.io/crumb)

## Controls
- arrow keys / WASD: move
- shift: sneak (slower, but the feet aim worse)
- space: start / retry

## About
Made in Godot 4 for the jam theme "I'm just a little guy".
Code written with help from Claude (Anthropic). Art and game design by me.
